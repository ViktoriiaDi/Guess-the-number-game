# Guess the Number
[![React CI/CD Case](https://github.com/ViktoriiaDi/Guess-the-number-game/actions/workflows/ci-cd.yml/badge.svg)](https://github.com/ViktoriiaDi/Guess-the-number-game/actions/workflows/ci-cd.yml)

Live demo: https://guess-the-number-game-one-beta.vercel.app/
## Опис проекту (MVP)
Це простий React-додаток, де користувач намагається вгадати випадкове число від 1 до 100. Гра веде історію спроб, повідомляє, чи число більше або менше, та попереджає, якщо число вже було введене або виходить за межі.


Мета MVP — реалізувати базову гру з перевіркою введеного числа, історією спроб та повідомленнями про правильні/неправильні спроби для виконання лабораторних робіт з дисципліни "Управління IT-проєктами"


## Встановлення та запуск
1. Клонування репозиторію: 
```bash
git clone https://github.com/ViktoriiaDi/Guess-the-number-game.git
```
2.Перехід у папку проєкту:
```bash
cd repo_name
```
3. Встановлення пакетів NPM:
```bash
npm install
```
4. Запуск проєкту у режимі розробки:
```bash
npm start
```
5.Відкриття додатку у браузері:
Зазвичай автоматично відкривається http://localhost:3000. Якщо ні — відкрий це посилання вручну.
